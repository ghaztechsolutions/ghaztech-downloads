## Getting an application

Open **[Releases](../../releases)** and download the file attached to the
latest release for the application you want.

Every release lists the **file size** and a **SHA-256 checksum**. Please check
both before installing — it is how you confirm the file you received is the one
we published.

On Windows:

```powershell
Get-FileHash .\TheFileYouDownloaded.exe -Algorithm SHA256
```

If the hash matches the release notes, the file is intact. If it does not, do
not install it — email ghaztechsolutions@gmail.com and tell us.

## "Windows protected your PC"

Windows SmartScreen shows that warning for any new software until enough people
have installed it for the publisher to be recognised. It is expected, and it is
not a sign that anything is wrong. Check the checksum above, then choose **More
info → Run anyway**.

## What these applications do with your data

Desktop applications keep their records in a file on your own computer. Nothing
is uploaded to GhazTech, and there is no account to create before you can use
one. You can export your data at any time.
